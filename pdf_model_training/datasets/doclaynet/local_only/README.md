# Local-Only DocLayNet Workspace

This directory is reserved for future shared DocLayNet local-only cache,
extraction, and raw-index work.

The currently observed full cache remains at the historical path:

```text
pdf_model_training/text_block_classifier/local_only/datasets/doclaynet/cache/
```

Do not copy or move those large zip files into this directory without an
explicit migration task.

Allowed local-only subtrees:

```text
cache/
extracted/
raw_index/
```

Nothing in those subtrees should be committed.
