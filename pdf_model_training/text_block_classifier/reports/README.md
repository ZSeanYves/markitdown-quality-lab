# Text Block Classifier Reports

This directory tracks small review reports distilled from local-only training
and evaluation artifacts.

Full prediction dumps, model checkpoints, feature matrices, visual packs, and
large local eval files remain under:

```text
pdf_model_training/text_block_classifier/local_only/
```

Tracked reports must summarize:

* dataset and subset version
* feature-set version
* model kind
* heldout metrics
* high-confidence hint behavior
* artifact paths that remain external-only
* runtime eligibility decision
