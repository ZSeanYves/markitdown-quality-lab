# External Benchmark Licenses

Keep source-level license, notice, attribution, and review notes here.

Use one directory per `source_group`:

```text
_licenses/<source_group>/LICENSE
_licenses/<source_group>/NOTICE
_licenses/<source_group>/attribution.txt
_licenses/<source_group>/review.md
```

Do not mark a payload row as redistributable until the source license and
payload provenance have been reviewed.
